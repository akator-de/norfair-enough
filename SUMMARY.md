norfair-enough is a maintained fork of tryolabs/norfair, a lightweight Python library for real-time multi-object tracking that can be plugged into virtually any object or keypoint detector. Its core `norfair` package provides a `Tracker` built on a Kalman filter (`kalman_filter.py`, `filter.py`) with pluggable distance functions (`distances.py`) for matching detections to tracked objects across frames. Additional modules cover camera motion estimation (`camera_motion.py`), video I/O and drawing helpers (`video.py`, `utils.py`), and MOT metrics support (`metrics.py`). A wide collection of runnable demos under `demos/` shows integration with detectors such as YOLOv5/v7, YOLO-NAS, Detectron2, AlphaPose, OpenPose, SAHI, and MediaPipe Objectron, including advanced use cases like re-identification, 3D tracking, and moving-camera scenarios. The project keeps the upstream Python API stable (`from norfair import ...`) while modernising packaging, CI, and documentation for continued production use.
